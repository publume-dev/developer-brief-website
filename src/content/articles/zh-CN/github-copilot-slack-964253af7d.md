- GitHub 集成现已将 GitHub Copilot CLI 和 Copilot 应用的代理能力引入 Slack，公开预览。
- 用户可在 Slack 中提及 @GitHub 启动代理会话，代理可回答问题、分类缺陷、调查失败、实施更改并开启拉取请求。
- 公开预览适用于 GitHub Copilot Business 和 Enterprise 计划的组织，使用量计入现有 Copilot 配额。
- 仓库管理员可要求对以 Copilot 应用身份提交的拉取请求在合并前进行额外审批，且这一要求仍然有效。
