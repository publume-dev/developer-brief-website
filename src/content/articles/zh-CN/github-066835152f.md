- GitHub 印度客户现可在月度与年度账单上使用符合条件的已保存信用卡进行自动循环付款。
- 此次更新通过支付授权（又称电子授权）来授权未来扣款，符合印度储备银行的要求。
- 保存或移除支付方式的操作方式不变；该功能适用于印度境内支持循环卡付款的付费 GitHub 产品。
