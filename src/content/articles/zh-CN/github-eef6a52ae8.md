- GitHub 的更新说明宣布，线程级通知设置中的 Customize 选项将被移除，之后每个线程只能选择 Subscribed 或 Not subscribed。
- 现有自定义线程订阅会被转换为 Subscribed，用户将收到这些线程中所有事件的通知。
- 多数用户无需立即操作；依赖自定义订阅的用户应在推送过程中检查自己的通知设置。
- 更新说明没有给出具体的推送时间表或生效日期。
