- 支持按令牌类型和用户撤销或取消授权用户凭据，比以往的全量开关控制更精细。
- 企业所有者、组织管理员以及具有“管理企业凭据”权限的成员，可撤销特定凭据类型（如个人访问令牌、SSH 密钥、OAuth 应用令牌或 GitHub App 用户访问令牌）的所有令牌，以控制泄露影响范围。
- 新增按令牌类型的批量取消授权，可通过 UI 或企业 REST API 撤销整个企业或特定用户的某类凭据的所有 SSO 授权。
- 按令牌类型的批量撤销可删除或撤销特定类型的所有用户级凭据，例如删除单个 EMU 用户的所有个人访问令牌而不影响 SSH 密钥。
- 之前企业级可用的所有批量凭据撤销操作，现已在组织级通过 Web UI 和组织 REST API 提供。
- 所有取消授权和撤销操作都会记录在审计日志中，并会向受影响的用户发送电子邮件通知。

安全团队现在可以在事件响应中快速按令牌类型或用户批量撤销凭据，降低意外中断风险并缩小爆炸半径。

该功能是否适用于 GitHub Enterprise Server 或仅适用于 GitHub.com 尚不明确，受影响版本的用户应查阅官方文档。
