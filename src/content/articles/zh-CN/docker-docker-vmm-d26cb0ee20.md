- Docker 推出 Docker VMM，这是一个用于 Docker Desktop 的第一方虚拟化层，取代了第三方组件，现已随 Docker Desktop 4.86 进入公开测试版（Mac 自动启用，Windows 选择启用）。
- Docker VMM 旨在提升容器启动性能、文件共享和内存效率，通过将空闲容器的未使用内存归还给宿主机，在 Windows 上尤其受益。
- 同一虚拟化引擎驱动 Docker Sandboxes，Docker 计划统一笔记本电脑、云端和本地的运行时；Linux 支持计划在预计于 10 月底发布的正式版中提供。
