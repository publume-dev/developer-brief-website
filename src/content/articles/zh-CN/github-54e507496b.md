- GitHub 推送规则现在支持路径例外，处于公开预览阶段，允许规则对特定文件路径豁免。
- 例外在设置推送规则时的“允许的例外”下配置，保存时验证模式。
- 截至本变更日志，支持例外的两种推送规则是“限制文件路径”和“限制文件大小”。
