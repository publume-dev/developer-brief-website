- GitHub 宣布 Project HydraFusion，一个 GitHub Copilot 中的研究预览，运行时多模型编排为每个任务选择三种执行模式之一（Single、Cascade、Critique）。
- 相比 Claude Opus 5，HydraFusion 在 TerminalBench 2.1 上验证任务质量提升 4.9 个百分点，估计成本降低 67%。
- 在研究预览中，HydraFusion 可像 GitHub Copilot 中的其他模型一样被选择，适合从首轮单提示编码任务开始使用。

开发者在评估采用 HydraFusion 时，应关注实际工作负载中的效果，因为公告中基准测试来自受控离线评估，真实场景结果可能不同。
