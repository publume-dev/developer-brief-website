- GitHub 提供基于仓库使用情况的“建议标签”和基于个人使用情况的“最近使用标签”，以加快标签查找。
- GitHub 支持归档标签，使其不再出现在标签选择器中，但保留在现有问题上的历史记录。
- 归档标签可随时从仓库的“标签”页面取消归档。
