- Grok 4.6，xAI 的最新推理模型，正在 GitHub Copilot 中推出。
- 该模型按提供商列表价格计费，采用基于使用的计费方式。
- 适用于 Copilot Pro、Pro+、Max、Business 和 Enterprise 订阅。
- 可在 Visual Studio Code、Visual Studio、Copilot CLI、GitHub Copilot 云代理、GitHub Copilot 应用、JetBrains、Xcode 和 Eclipse 的模型选择器中选择。
- 对于 Copilot Enterprise 和 Business 计划，管理员必须在 Copilot 设置中启用 Grok 4.6 策略，因为它默认关闭。
