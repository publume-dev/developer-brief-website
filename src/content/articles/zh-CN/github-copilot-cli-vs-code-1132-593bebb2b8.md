- Copilot 应用的 Auto 现在会显示每个已完成请求所使用的模型，并在可用时显示 AI 积分和缓存详情。
- GitHub Copilot CLI 新增 Sessions 侧边栏，用于管理多个并发会话，并提供打开、关闭和切换会话的快捷键。
- GitHub Copilot CLI 新增实验性 /worktree 命令，可创建隔离的 worktree 和单独的对话。
- GitHub Copilot CLI 的 /rewind 命令可在不使用 Git 的情况下恢复 Copilot 更改过的对话和文件，同时保留后续编辑。
- VS Code 1.132 集成的浏览器支持元素级反馈，可选择并标注特定网页元素发送给 agent。
- VS Code 听写现在默认使用多语言设备端模型，音频保留在设备上。
- VS Code 新增 /btw 命令，可打开一个侧边聊天，共享主对话的上下文和提示词缓存，并可在 Agents 窗口中使用。
- Markdown 差异现在可在实验性混合 Markdown 编辑器中打开，并显示新增、更改和删除内容的装订线指示器。
