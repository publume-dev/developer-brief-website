- 在个人账户或组织中屏蔽用户时，现在可以选择自动关闭该用户所有开放的议题、讨论和拉取请求。
- 该选项位于屏蔽对话框中，可通过评论或“设置 → 审核 → 已屏蔽用户”进入。
- 尚不确定此功能是否适用于所有 GitHub 套餐（免费版、专业版、团队版、企业版）或仅限于特定层级。
