- MAI-Code-1-Flash 将于 2026 年 9 月 10 日在所有 GitHub Copilot 体验中弃用。
- GitHub 建议改用 MAI-Code-1.1-Flash；工作流和集成必须在弃用日期前更新为使用该模型。
- GitHub Copilot Enterprise 管理员可能需要在弃用日期前通过 Copilot 设置中的模型策略启用对 MAI-Code-1.1-Flash 的访问。
- 弃用后无需采取任何操作来移除旧模型。
