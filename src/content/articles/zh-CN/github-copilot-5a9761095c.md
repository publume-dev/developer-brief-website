- Copilot 影响仪表板现在包含“潜在投资回报”板块，将 Copilot 支出与拉取请求产出关联。
- 该板块显示两张卡片，分别对比被动用户（聊天和代码补全，第一阶段）与 Agent 优先开发者（第二阶段和第三阶段）；每张卡片展示每位开发者每月成本、成本占薪酬的百分比，以及每位开发者每月的拉取请求数。
- 薪酬选择器允许管理员选择薪酬档位并即时重算成本相关指标。
- 队列用户计数现在反映整个 28 天报告窗口内活跃的所有用户，而非仅窗口最后一天活跃的用户，因此队列计数明显更高。
- 该板块适用于企业和组织层级，面向企业所有者、账单管理员、组织所有者以及拥有 View Copilot Metrics 权限的自定义角色；必须启用 Copilot 使用情况指标策略。
- 成本数字是基于 AI 信用消耗的估算值，薪酬选择器是建模输入而非实际薪酬数据；这些指标是方向性的。
