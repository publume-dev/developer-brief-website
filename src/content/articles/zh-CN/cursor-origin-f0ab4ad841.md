- Cursor 已发布 Origin，一个内置于其 AI 驱动的编辑器中的基于 git 的代码托管平台，可通过 Cursor 应用中的新 Codebase 标签页访问，目前向 Pro、Teams 和 Enterprise 计划的用户提供早期测试。
- Origin 支持仓库创建、拉取请求和基于浏览器的代码导航，并提供 git 指南，涵盖通过 HTTPS 或 Origin CLI 进行克隆、推送和拉取。
- Origin 支持从 GitHub 拉取并保持同步的镜像仓库，但对于这些项目的推送操作仍会发送到 GitHub，GitHub 仍然是记录系统。
- Origin 被定位为“代理原生基础设施”和“代理时代的 git 锻造厂”，具有堆叠拉取请求和代理感知合并队列等功能，这得益于 Cursor 在 2025 年收购 Graphite。
- Origin 仅对付费客户开放，企业管理员可以选择退出测试版。

值得关注的是，Origin 目前没有明确的数据保留或训练使用政策，这引发了关于托管代码可能在 SpaceX 和 xAI 生态系统中如何使用的问题，尽管目前没有进一步细节。
