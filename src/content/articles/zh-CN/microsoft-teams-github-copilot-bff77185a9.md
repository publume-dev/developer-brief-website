- 新的公开预览：在 Microsoft Teams 中可通过提及 @GitHub 启动 GitHub Copilot 云代理会话，任何对仓库有写权限的参与者均可触发 Copilot 进行更改。
- 可用性：适用于付费 GitHub Copilot 计划，消耗 AI 额度；管理员需启用 GitHub Copilot 云代理和云沙盒供组织使用。
- 安全控制：仓库管理员可要求对来自 Microsoft Teams Copilot 集成身份的拉取请求进行额外审批，确保在代理生成的工作合并前有人工审查。
