- GitHub Apps 现在可以被授予企业账单权限（读取或读写），允许应用安装令牌调用企业账单 REST API 端点。
- 此前，通过 API 读取使用情况或管理预算和成本中心需要属于企业所有者或账单管理员的个人访问令牌。
- 新的企业账单权限在 GitHub Enterprise Cloud 上可用，且应用安装令牌的速率限制高于个人访问令牌。
