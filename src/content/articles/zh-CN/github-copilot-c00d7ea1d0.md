- GitHub Copilot 代码审查现在能够在每次审查的概述评论中提供批准评估，表明拉取请求是否可批准。
- 启用后，Copilot 可以提交批准，计入仓库的必需批准规则；该功能默认关闭，可在企业、组织和仓库级别配置。
- Copilot 的批准在批准后推送新提交时会被撤销；可以请求新的 Copilot 审查以获得新的批准。
- 此功能在公共预览中可用于 GitHub Copilot Pro、Pro+、Max、Business 和 Enterprise 计划。
