- 组织和企业所有者可以发布自定义智能体，Visual Studio 会自动检测，并在智能体选择器中显示描述和来源。
- 受支持的模型现在提供低、中、高三种思考强度选项，以平衡推理深度与令牌消耗。
- 用户可以固定常用模型、折叠不常用的模型，并通过管理视图查看模型功能、上下文窗口大小和成本信息。
- Git 智能体能够在打开拉取请求之前审查未提交的更改或提交，在 Git 更改中以内联和可导航列表的形式显示发现，并支持 GitHub 和 Azure DevOps 仓库。
- 用户可以通过提示框中的“查看所有 Copilot 使用情况”查看完整的 Copilot 计划详情，并在接近限制时收到改进的通知。
- 八月更新适用于所有 GitHub Copilot 计划的用户，包括 Free、Student、Pro、Pro+、Max、Business 和 Enterprise。
