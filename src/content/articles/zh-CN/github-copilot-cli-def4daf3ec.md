- 内容排除功能现已在 GitHub Copilot 应用和 Copilot CLI 中全面推出，遵守企业、组织和仓库管理员配置的策略。
- 启用后，Copilot 不会将排除的文件用作上下文，有助于在代理工作流中保护敏感代码。
- 该功能适用于 Copilot Business 和 Copilot Enterprise 客户。
