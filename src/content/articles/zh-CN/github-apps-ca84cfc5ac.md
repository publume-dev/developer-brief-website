- 企业所有者现在可以将企业外部创建的公开 GitHub Apps 安装到企业账户。
- 企业级安装只授予应用对企业账户本身的访问权限，不会授予对企业内组织或仓库的访问权限。
- 所有用户和组织现在都可以创建带企业权限的 GitHub Apps。
- 带 Enterprise organization installations 和 Enterprise organization installation repositories 权限的应用不能跨企业边界安装。
- 使用这些权限的应用不能安装到多个企业；已安装到多个企业的应用也不能再添加这些权限。
- 企业权限 API 可以管理企业内所有组织的应用安装；在供跨企业使用前还需额外的安全保护措施。
