- MAI-Code-1.1-Flash 是微软最新的小尺寸编程模型，正在 GitHub Copilot 中推出，具备原生视觉支持，并在代码质量、指令遵循、工具使用和性能方面有所改进。
- 该模型定价比 MAI-Code-1-Flash 低 73%；年度 GitHub Copilot 订阅用户按 0.25 倍高级请求倍率计费。
- Copilot Free 和 Student 用户可通过自动模型选择使用该模型；Pro、Pro+、Max、Business 和 Enterprise 订阅可在模型选择器中手动选择，覆盖 Copilot CLI、云端代理、应用、GitHub 上的 Chat、VS Code、Visual Studio、GitHub Mobile、JetBrains IDE、Eclipse 和 Xcode。
- Copilot Enterprise 和 Business 管理员必须在 Copilot 设置中启用 MAI-Code-1.1-Flash 策略，且该策略默认关闭。
