- GitHub Code Quality 现已在 GitHub Enterprise Cloud 和 GitHub Team 上正式可用，但 GitHub Enterprise Server 不在本次发布范围内。
- 该服务结合 CodeQL 分析与 AI 辅助的维护性和可靠性问题检测，并使用 Copilot Autofix 在拉取请求中建议更改。
- 正式发布版新增组织级启用、维护性和可靠性评分仪表板、测试覆盖率指标，以及用于质量门的规则集。
- 这是独立付费产品，价格为每位活跃提交者每月 10 美元；AI 辅助检测和 Copilot Autofix 另有按使用量计费，且该产品不属于 GitHub Advanced Security。
- 自 2025 年 10 月启动公开预览以来，已有超过 10,000 家企业使用该产品。
- GitHub 称，其自有工程组织中 67.3% 的 Code Quality 发现项在拉取请求合并前得到解决；GitHub 将此作为早期衡量指标，该数据为 GitHub 自报，并非独立基准。
