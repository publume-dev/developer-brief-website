- GitHub Copilot 代码审查的 effort levels 现已正式发布，名称由公开预览阶段的 Low、Medium 改为 Lite、Balanced。
- 已有的 effort level 配置会自动沿用，并对应到新名称。
- 组织管理员可以为所有仓库设置默认 effort level；仓库如未单独配置，将继承该默认值。
- Copilot 代码审查现在会在时间线事件和 pull request 概览评论中标注实际使用的 effort level。
