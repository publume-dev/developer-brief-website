- **新代理**：Google Cloud 推出了 AI 驱动的数据库运维代理，包括 Onboarding Agent（简化数据库设置）和 Observability Agent（自动化故障排查、性能优化和调优）。
- **集成与服务**：这些代理与 Gemini Cloud Assist 集成，支持 AlloyDB、Bigtable 和 Spanner 等数据库服务。
- **遥测与根因分析**：Observability Agent 可连接 Database Insights、Cloud Monitoring、Cloud Logging 和 Cloud Trace 的遥测数据，在几分钟内提供根因分析。
- **可用性**：该能力通过 Gemini/Cloud Assist 聊天、Google Cloud 控制台、CLI 工具以及 IDE（如 Antigravity）提供，也可通过 MCP 服务器使用。
