- DoorDash reports its Flux platform executed 130,000 engineering tasks in a single month and supports over 25,000 automated code reviews per week.
- Flux uses Firecracker microVMs for isolation, an in-house MCP gateway named Agent Gateway for scoped permissions and auditing, and YAML-defined playbooks.
- Flux achieves a 95th percentile service level objective of less than five seconds for end-to-end sandbox setup.
- DoorDash moved to cloud-based agent execution to avoid laptop resource limits and to improve security, monitoring, and enterprise guardrails.
