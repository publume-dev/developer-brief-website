- GitHub's changelog announces that the GitHub Enterprise Server 3.22 release candidate is now available.
- Administrators can configure Copilot CLI to work with GHES in disconnected or air-gapped environments without connectivity to GitHub Cloud; this capability is in technical preview and subject to change.
- Enterprise Teams, previously in public preview, is now generally available, letting enterprise owners manage users and access across organizations and repositories from a centralized team structure.
- Security analysts can sort secret scanning push protection bypass requests and alert dismissal requests by date in ascending or descending order at repository, organization, and enterprise levels.
- Repository rulesets now support bypassing by individual users, giving administrators more granular control over rule bypass permissions.
- Organization owners and repository administrators can require specific reviewers for pull requests via a required reviewers rule, targeting branches, files, and folders with pattern matching and a minimum number of required reviews per team.
- Developers can see release status directly in the issue sidebar, with a "Latest release" or "Pre-release" badge when a linked pull request is included in a release.
- Maintainers can see contributor role labels such as "First-time contributor," "Contributor," and "Member" directly in the pull request list view for public repositories.
