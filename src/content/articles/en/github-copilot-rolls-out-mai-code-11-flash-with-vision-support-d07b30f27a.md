- MAI-Code-1.1-Flash, Microsoft’s latest small-tier coding model, is rolling out in GitHub Copilot with native vision support and improvements in coding quality, instruction following, tool use, and performance.
- It is priced 73% lower than MAI-Code-1-Flash; annual GitHub Copilot subscribers are charged a 0.25x premium request multiplier.
- Copilot Free and Student users get the model through auto model selection, while Pro, Pro+, Max, Business, and Enterprise SKUs can manually select it in the model picker across Copilot CLI, cloud agent, app, Chat on GitHub, VS Code, Visual Studio, GitHub Mobile, JetBrains IDEs, Eclipse, and Xcode.
- Copilot Enterprise and Business administrators must enable the MAI-Code-1.1-Flash policy in Copilot settings, and the policy is off by default.
