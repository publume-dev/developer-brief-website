- The GitHub integration in Slack now brings the agentic capabilities of GitHub Copilot CLI and the GitHub Copilot app into Slack in public preview.
- Users can mention @GitHub in Slack to start an agent session that can answer questions, triage bugs, investigate failures, implement changes, and open pull requests.
- The public preview is available to organizations on GitHub Copilot Business and GitHub Copilot Enterprise plans, with usage counting against existing Copilot entitlements.
- Repository administrators can require an additional approval for any pull request attributed to the Copilot app identity before it can merge.
