- Roblox extracted 1.75 million review comments from 700,000 PRs over 3 years and clustered them into 'exemplars'—testable YAML rules used to guide AI agents during code review.
- In Roblox's automated code review agent, adding exemplars raised the acceptance rate of agent suggestions to about 68-70%.
- Roblox built custom sandboxes for AI agents, implementing just-in-time permissions, least privileged access, no long-running secrets, and auditable agent identities distinct from humans.
- The talk describes Roblox's internal approaches but provides limited quantitative evidence or independent evaluation of the claimed acceptance rate and security effectiveness.
