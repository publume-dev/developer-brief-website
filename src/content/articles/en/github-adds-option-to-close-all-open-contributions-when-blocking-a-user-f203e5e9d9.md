- When blocking a user from a personal account or organization, GitHub now allows you to automatically close all open issues, discussions, and pull requests authored by that user.
- The option appears in the block dialog, accessible when blocking from a comment or from Settings → Moderation → Blocked users.
- It is uncertain whether this feature is available on all GitHub plans (Free, Pro, Team, Enterprise) or limited to certain tiers.
