- Gemini 3.7 Flash is rolling out in GitHub Copilot.
- Early testing indicates improvements in web and app development and agentic coding workflows over the previous version (no quantitative evidence).
- Available to Copilot Pro, Pro+, Max, Business, and Enterprise users.
- Selectable in VS Code, Visual Studio, Copilot CLI, GitHub Copilot cloud agent, GitHub Copilot app, JetBrains, Xcode, and Eclipse.
- Copilot Enterprise and Business plan administrators must enable the Gemini 3.7 Flash Preview policy in Copilot settings before their organization can select it.
