- Copilot code review effort levels are now generally available under the names Lite and Balanced, replacing the public preview names Low and Medium.
- Existing effort level configurations carry forward automatically under the new names.
- Organization admins can set a default effort level that applies to all repositories; repositories inherit that default unless they set their own.
- Copilot code review now labels the effort level used in timeline events and the pull request overview comment.
