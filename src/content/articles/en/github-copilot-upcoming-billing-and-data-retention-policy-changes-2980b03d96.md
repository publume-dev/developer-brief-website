- Starting September 1, 2026, GitHub will reenable sign-ups for new Copilot Business and Enterprise customers paying by credit card or PayPal, and all new seat assignments will require payment before users gain access.
- For existing Copilot Business and Enterprise customers with credit card or PayPal, all assigned seats will incur an upfront charge starting October 1, 2026.
- No earlier than September 28, 2026, GitHub will unify Copilot Chat on github.com, Copilot Chat in GitHub Mobile, and GitHub Copilot cloud agent into a single experience enabled by default, with chat data retained for the life of the account instead of 28 days.
- Starting September 28, 2026, the default review effort level for GitHub Copilot code review changes from Lite to Balanced; organizations and repositories can opt to keep Lite by explicitly selecting it before that date.
