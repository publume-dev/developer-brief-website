- Organization and enterprise owners can publish custom agents that are automatically detected by Visual Studio, with descriptions and source shown in the agent picker.
- Supported models now offer Low, Medium, and High thinking effort controls to balance reasoning depth with token usage.
- Users can pin favorite models, collapse less-used ones, and access a management view with model capabilities, context window sizes, and cost information.
- The Git agent can review uncommitted changes or commits before opening a pull request, showing findings inline and in a navigable list in Git Changes, and works with GitHub and Azure DevOps repositories.
- Users can view full Copilot plan details from the prompt box via 'View all Copilot usage', with refined notifications when approaching limits.
- The August 2026 update is available to users on all GitHub Copilot plans, including Free, Student, Pro, Pro+, Max, Business, and Enterprise.
