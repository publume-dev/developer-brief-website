- VoidZero released Vite+ beta, a unified web toolchain that manages runtime, package manager, and frontend tools behind a single 'vp' command.
- Vite+ integrates Vite, Vitest, Rolldown, tsdown, Oxlint, and Oxfmt with a built-in task runner, and is MIT-licensed and framework-agnostic.
- Since alpha, over 500 pull requests have been merged, adding smarter caching for 'vp run', wider migration coverage, enterprise features like organization templates and proxy-aware HTTP, and more than 180 fixes.
- More than 1,300 public repositories depend on Vite+, with adoption spanning Dify, BlockNote, and Cloudflare's vinext.
- Existing projects can adopt Vite+ via 'vp migrate', which previews changes, though complex setups may require manual follow-up.
