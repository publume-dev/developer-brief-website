- GitHub Copilot code review now provides an approval assessment in the overview comment of every review, indicating whether a pull request is ready to approve.
- When enabled, Copilot can submit an approval that counts toward a repository's required-approvals rule; the feature is off by default and configurable at enterprise, organization, and repository levels.
- Copilot approvals are dismissed if new commits are pushed after approval; a new review from Copilot can be requested to get a fresh approval.
- This feature is available in public preview to GitHub Copilot Pro, Pro+, Max, Business, and Enterprise plans.
