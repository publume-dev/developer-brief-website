- The Agents window now supports arranging chats side by side, and the layout is restored when you return to the session.
- The /btw command opens a side chat that shares the primary chat's context and prompt cache.
- Portable agent plugins that follow the Agent Plugins 1.0 standard can now be installed in VS Code.
- In Claude sessions, users can switch between models from their Anthropic subscription and Copilot subscription.
- VS Code can now continue external agent sessions created in other applications from the Sessions list.
- The Agent Host can connect multiple VS Code windows to the same agent session.
- The experimental /rubber-duck command in Agent Host sessions asks a complementary model to surface missed details and edge cases.
- Chat transcript now supports text search with options like case matching, whole words, and regular expressions.
- Sticky scrolling keeps the current prompt pinned while scrolling through long conversations.
- The integrated browser can now select and annotate HTML elements to provide UI feedback to agents.
- Local HTML files automatically reload when they change on disk in the integrated browser.
- Built-in dictation now supports multiple languages, project-specific instructions, and shell-aware cleanup for terminal commands.
