- Cursor has launched Origin, a git-based code hosting platform embedded inside its AI-powered editor, accessible via a new Codebase tab in the Cursor application, available in early beta on Pro, Teams, and Enterprise plans.
- Origin supports repository creation, pull requests, and browser-based code navigation, and provides a git guide for cloning, pushing, and pulling over HTTPS or with the Origin CLI.
- Origin supports mirrored repositories pulled from GitHub and kept in sync, but pushes for those projects still go to GitHub, which remains the system of record.
- Origin is positioned as "agent-native infrastructure" and a "git forge for the agentic era," with features like stacked pull requests and agent-aware merge queues, helped by Cursor's acquisition of Graphite in 2025.
- Origin is available only to paying customers, and enterprise administrators can opt out of the beta.

Origin ships without clear data retention or training use policies, raising questions about how hosted code might be used within the SpaceX and xAI ecosystems, though no further details are provided.
