- GitHub Code Quality is now generally available on GitHub Enterprise Cloud and GitHub Team; GitHub Enterprise Server is not included at launch.
- The service combines CodeQL analysis with AI-assisted detection of maintainability and reliability problems and uses Copilot Autofix to suggest changes in pull requests.
- The general availability release adds organization-wide enablement, dashboards with maintainability and reliability scores, test coverage metrics, and rulesets for quality gates.
- It is a separate paid product priced at $10 per active committer per month, with additional usage-based charges for AI-assisted detection and Copilot Autofix; it is not part of GitHub Advanced Security.
- More than 10,000 enterprises used the product during the public preview that began in October 2025.
- GitHub reports that 67.3% of Code Quality findings in its own engineering organization are resolved before pull requests are merged; GitHub presents this as an early measure, and the figure is self-reported rather than an independent benchmark.
