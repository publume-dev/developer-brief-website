- Docker has introduced Docker VMM, a first-party virtualization layer for Docker Desktop, replacing third-party components, now in public beta with Docker Desktop 4.86 (enabled automatically on Mac, opt-in on Windows).
- Docker VMM is designed to improve container startup performance, file sharing, and memory efficiency by returning unused memory to the host when containers are idle, with particular benefits on Windows.
- The same virtualization engine powers Docker Sandboxes, and Docker plans to unify runtime across laptops, cloud, and on-prem; Linux support is planned for the general availability release expected at the end of October.
