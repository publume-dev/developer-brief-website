- Copilot app Auto now shows the model that handled each completed request, plus AI credit and cache details when available.
- GitHub Copilot CLI adds a Sessions sidebar for managing multiple concurrent sessions, with shortcuts to open, close, and move between sessions.
- GitHub Copilot CLI adds an experimental /worktree command that creates an isolated worktree and a separate conversation.
- GitHub Copilot CLI's /rewind command can restore the conversation and files Copilot changed without Git while preserving subsequent edits.
- The VS Code 1.132 integrated browser supports element-level feedback, allowing selection and annotation of specific web page elements to send to the agent.
- VS Code dictation now defaults to a multilingual on-device model, keeping audio on the device.
- VS Code adds a /btw command that opens a side chat sharing context and prompt cache from the primary conversation, and works in the Agents window.
- Markdown diffs can now be opened in the experimental hybrid Markdown editor, with gutter indicators for added, changed, and deleted content.
