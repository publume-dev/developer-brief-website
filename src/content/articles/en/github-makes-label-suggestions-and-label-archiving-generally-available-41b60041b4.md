- GitHub now offers Suggested Labels based on repository usage and Recent Labels based on personal usage to help find labels faster.
- GitHub now supports archiving labels so they no longer appear in the label picker, while preserving their history on existing issues.
- Archived labels can be unarchived anytime from the repository Labels page.
