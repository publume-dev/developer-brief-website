- Enterprise owners can now install public GitHub Apps created outside their enterprise onto their enterprise account.
- An enterprise-level installation grants the app access to the enterprise account itself, but not to its organizations or repositories.
- All users and organizations can now create GitHub Apps with enterprise permissions.
- Apps that request the Enterprise organization installations or Enterprise organization installation repositories permissions cannot be installed across enterprise boundaries.
- Such an app cannot be installed across multiple enterprises, and an app already installed across multiple enterprises cannot add these permissions.
- The enterprise permissions API set can manage all app installations across an enterprise's organizations, and additional safeguards are required before it can be released for cross-enterprise use.
