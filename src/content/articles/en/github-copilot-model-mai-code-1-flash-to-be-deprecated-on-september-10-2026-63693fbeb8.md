- MAI-Code-1-Flash will be deprecated across all GitHub Copilot experiences on September 10, 2026.
- GitHub suggests MAI-Code-1.1-Flash as the alternative; workflows and integrations must be updated to use it before the deprecation date.
- GitHub Copilot Enterprise administrators may need to enable access to MAI-Code-1.1-Flash through model policies in Copilot settings before the deprecation date.
- No action is required to remove the older model after deprecation.
