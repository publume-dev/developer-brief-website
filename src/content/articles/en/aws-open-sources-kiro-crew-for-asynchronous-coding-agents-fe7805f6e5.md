- AWS open-sourced Kiro Crew, a system for running multiple Kiro coding agents across sessions, tools, and tasks, supporting asynchronous work like incident investigation and ticket triage.
- Kiro Crew orchestrates agents through the Agent Client Protocol (ACP) and provides live visibility into agent plans, tool calls, approval gates, and results via an Activity view.
- Security features include an OS-level sandbox, denied-by-default commands, suspicious-pattern blocking, credential redaction, and a signed audit log.
- Kiro Crew runs on Kiro CLI, can use existing .kiro configurations, and is released under Apache 2.0 for macOS, Linux, and Windows with Slack, Telegram, and WeCom integrations.
- Internally developed as MeshClaw, Kiro Crew was adopted by more than 39,000 developers at Amazon.
