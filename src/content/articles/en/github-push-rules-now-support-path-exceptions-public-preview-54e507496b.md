- GitHub push rules now support path exceptions, available in public preview, allowing rules to be exempted for specific file paths.
- Exceptions are configured under "Allowed exceptions" when setting up a push rule, and patterns are validated on save.
- As of this changelog, two push rules support exceptions: "Restrict file paths" and "Restrict file size".
