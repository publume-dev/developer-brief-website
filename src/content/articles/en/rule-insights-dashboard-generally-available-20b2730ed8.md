- The GitHub rule insights dashboard is now generally available at both repository and organization levels.
- The organization-level dashboard provides an aggregated view across all repositories, allowing review of aggregated rule evaluation metrics and identification of top repositories by bypasses, with filters for evaluation status, branch, ruleset, and date range.
- The repository-level dashboard shows successes, failures, and bypasses over time, along with the most active bypassers for rulesets, with charts linking to the rule insights page with prefilled filters.
- Rule insights dashboard data can be exported to CSV at both repository and organization levels for reporting and record keeping.
