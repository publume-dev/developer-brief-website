- New public preview: start GitHub Copilot cloud agent sessions in Microsoft Teams by mentioning @GitHub, and any participant with write access to the repository can trigger Copilot to make changes.
- Availability: requires paid GitHub Copilot plans, consumes AI credits, and needs an administrator to enable GitHub Copilot cloud agent and cloud sandboxes for organizational use.
- Security control: repository administrators can require an additional approval for any pull request attributed to the Microsoft Teams Copilot integration identity, ensuring human review before agent-authored work ships.
