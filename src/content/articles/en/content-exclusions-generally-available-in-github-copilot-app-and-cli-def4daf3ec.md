- Content exclusion is now generally available in the GitHub Copilot app and Copilot CLI, respecting policies configured by enterprise, organization, and repository administrators.
- With content exclusion, Copilot will not use excluded files as context, helping protect sensitive code across agentic workflows.
- Content exclusion is available for Copilot Business and Copilot Enterprise customers.
