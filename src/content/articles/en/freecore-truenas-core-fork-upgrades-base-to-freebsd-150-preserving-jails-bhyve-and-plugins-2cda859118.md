- FreeCORE, a community fork of TrueNAS CORE, upgrades the 13.3 base to FreeBSD 15.0 and is currently stable as version 15.0-U1, with 15.1 anticipated next.
- FreeCORE preserves FreeBSD Jails, native plugins, and bhyve virtual machines, which were deprecated by upstream iXsystems as it shifted to TrueNAS SCALE on Linux.
- FreeCORE offers an in-place upgrade path from the TrueNAS CORE 13.3 base to FreeBSD 15.0.
- The project is currently driven by a single maintainer who uses AI coding agents extensively for implementation and review.
- Community discussions highlight that OpenZFS native encryption lacks a dedicated upstream maintainer, leading some to prefer Linux LUKS unless native ZFS encryption is required.

FreeCORE's long-term viability is unproven; it relies on a single maintainer and community support, which is a risk for enterprise adoption.
