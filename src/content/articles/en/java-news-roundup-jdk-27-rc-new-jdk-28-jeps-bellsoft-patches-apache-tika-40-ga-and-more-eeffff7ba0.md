- JDK 27 has reached its first release candidate (Build 35) with no unresolved P1 bugs; GA is scheduled for September 15, 2026, and includes nine JEPs.
- JDK 28 targets JEP 541 (Deprecate the macOS/x64 Port for Removal) and JEP 540 (Simple JSON API, Incubator).
- BellSoft released CPU patches for Liberica JDK versions 26.0.2.1, 25.0.4.1, 21.0.12.1, 17.0.20.1, 11.0.32.1, 8u504, 7u513, and 6u513, addressing 29 CVEs.
- Apache Tika 4.0.0 GA adds a new MarkdownParser, inference and OCR modules for Claude, Gemini, OpenAI, and Tesseract, and includes breaking changes such as forked process parsing and JSON configuration.
- Helidon 4.5.3 maintenance release adds required configuration properties for LRA participant callbacks and a limit of 1000 nested JSON structures.
- Micrometer Metrics 1.18.0-M1 optimizes PrometheusMeterRegistry and MicrometerCollector, while Micrometer Tracing 1.8.0-M1 refactors W3CPropagation for security.
