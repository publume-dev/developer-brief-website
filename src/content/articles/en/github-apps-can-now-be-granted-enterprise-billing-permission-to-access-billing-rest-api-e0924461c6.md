- GitHub Apps can now be granted enterprise billing permission with read or read and write access, allowing app installation tokens to call enterprise billing REST API endpoints.
- Previously, reading usage or managing budgets and cost centers via the API required a personal access token belonging to an enterprise owner or billing manager.
- The new enterprise billing permission is available on GitHub Enterprise Cloud, and app installation tokens also get higher rate limits than personal access tokens.
