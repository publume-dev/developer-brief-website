- GitHub announced Project HydraFusion, a research preview in GitHub Copilot that performs runtime multi-model orchestration to choose among three execution patterns (Single, Cascade, Critique) per task.
- Compared with Claude Opus 5, HydraFusion is reported to improve verified task quality by 4.9 percentage points at 67% lower estimated cost on TerminalBench 2.1.
- In the research preview, HydraFusion can be selected like any other model in GitHub Copilot, and first-turn, single-prompt coding tasks are the best place to start.

Developers evaluating HydraFusion should consider that benchmark results stem from controlled offline evaluations, and real-world performance may differ.
