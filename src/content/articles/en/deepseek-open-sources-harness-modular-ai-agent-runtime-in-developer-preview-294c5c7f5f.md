- DeepSeek has announced a developer preview release of DeepSeek Harness (dsh), an open-source execution runtime released under the MIT license for constructing autonomous AI agents.
- DeepSeek Harness is built on the Cordis meta-framework and adopts a micro-kernel architecture where runtime components are isolated, interchangeable plugins.
- The platform includes an append-only event logging subsystem that records user messages, tool invocations, reasoning states, token metrics, and sub-agent dispatches into a unified execution trajectory.
- Version 0.1 preview introduces four baseline runtime configurations: Standard, Code, Minimal, and Creator modes.
