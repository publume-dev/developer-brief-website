- **New agents**: Google Cloud introduced AI-powered Database Operations Agents, including an Onboarding Agent that simplifies database setup and an Observability Agent that automates troubleshooting, performance optimization, and tuning.
- **Integration and services**: The agents are integrated with Gemini Cloud Assist and support multiple database services, including AlloyDB, Bigtable, and Spanner.
- **Telemetry and root cause analysis**: The Observability Agent connects telemetry from Database Insights, Cloud Monitoring, Cloud Logging, and Cloud Trace, providing root cause analysis in minutes.
- **Availability**: The capabilities are accessible through Gemini/Cloud Assist chat, Google Cloud console, CLI tools, and IDEs such as Antigravity, as well as via MCP servers.
