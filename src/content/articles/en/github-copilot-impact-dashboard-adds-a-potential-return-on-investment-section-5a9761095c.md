- The Copilot impact dashboard now includes a “Potential return on investment” section that connects Copilot spend to pull request output.
- The section shows two cards comparing passive users (chat and code completions, Phase 1) against agent-first developers (Phase 2 and Phase 3); each card displays cost per developer per month, cost as a percentage of payroll, and pull requests per developer per month.
- A salary selector lets administrators pick a compensation band and recalculates cost-derived metrics instantly.
- Cohort user counts now reflect every user active during the full 28-day reporting window rather than only users active on the window's final day, resulting in noticeably higher cohort counts.
- The section is available at enterprise and organization levels to enterprise owners, billing managers, organization owners, and custom roles with the View Copilot Metrics permission; the Copilot usage metrics policy must be enabled.
- Cost figures are estimates based on AI credit consumption, and the salary selector is a modeling input rather than actual payroll data; the metrics are directional.
