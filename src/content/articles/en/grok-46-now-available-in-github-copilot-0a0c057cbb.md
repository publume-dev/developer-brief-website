- Grok 4.6, xAI's latest reasoning model, is now rolling out in GitHub Copilot.
- It is billed at provider list pricing under usage-based billing.
- Available to Copilot Pro, Pro+, Max, Business, and Enterprise SKUs.
- Selectable in the model picker in Visual Studio Code, Visual Studio, Copilot CLI, GitHub Copilot cloud agent, GitHub Copilot app, JetBrains, Xcode, and Eclipse.
- For Copilot Enterprise and Business plans, administrators must enable the Grok 4.6 policy in Copilot settings, as it is off by default.
